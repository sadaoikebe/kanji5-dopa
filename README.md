# 漢字ブースト⑤

小学5年生の漢字193字を、60秒のタイムアタックで覚える1ファイルのブラウザゲーム。
演出は [sadaoikebe/speedometer](https://github.com/sadaoikebe/speedometer) の考え方を借りている
(ワープトンネルの背景シェーダー、3色パレットの循環、画面の縁ゲージ、バネで揺れる針と残像、衝撃波、花火、全画面フラッシュ、モード切替の裏返り)。

`index.html` をブラウザで開くだけで遊べる。通信なし。記録は localStorage に保存。

- 言葉の読みを見て、□に入る漢字を4択で選ぶ。タップ or 1〜4キー
- 速く答えるほど得点が上がる(神速 ×3 / FAST ×2)。COMBO 10 / 30 でギアが上がり、色が変わる。50 から金色
- まちがえた漢字は3問後にもう一度出る。まちがえた回数の多い漢字ほど出やすい
- 「苦手だけ特訓」はまちがえたことがあって、まだマスターしていない漢字だけを出す

調整用の定数は `index.html` の「調整用の定数」の段にある。
